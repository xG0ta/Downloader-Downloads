# Downloader

Descarga videos o solo el MP3 de uno o varios enlaces, en Windows y Mac.

## Descargar

Abre la [última versión](https://github.com/xG0ta/Downloader-Downloads/releases/latest) y baja el archivo de tu sistema:

- **Windows 10/11 x64:** `Downloader-Windows-x64.zip`. Extrae toda la carpeta y abre `Downloader.exe`.
- **Mac:** `Downloader-Mac.zip`. Extrae y abre `Downloader.app` con clic derecho → Abrir la primera vez.

La app se actualiza sola después de instalarla. No está firmada con certificado comercial, por eso el sistema puede avisar al abrirla.
